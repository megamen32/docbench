# Русскоязычный каталог задач DocBench

Это постоянная спецификация покрытия русского бенчмарка. Она фиксирует задачи,
контракты входа/выхода и метрики, но не дублирует внешние документы, вопросы
или gold-ответы. Внутренние примеры для каждого трека должны быть нашими либо
иметь явно подтверждённые условия использования.

Машиночитаемая версия: `datasets/russian_document_benchmark_catalog.yaml`.

## Основная документная дорожка

| Задача | Русский вход | Проверяемые навыки | Оценка | Приоритет |
| --- | --- | --- | --- | --- |
| LabTabVQA | Страница с таблицей + вопрос | Таблицы, OCR, арифметика | Exact match, answer judge, evidence | P0 |
| ruMathVQA | Страница с формулой/схемой + вопрос | OCR, арифметика, визуальное рассуждение | Exact match, answer judge, evidence | P0 |
| ruNaturalScienceVQA | Научная страница + вопрос | OCR, предметное и визуальное рассуждение | Exact match, answer judge, evidence | P1 |
| ruTiE-Image | Текстово-визуальная страница + вопрос | OCR, атрибуты, логика | Exact match, answer judge, evidence | P1 |
| SchoolScienceVQA | Учебная страница + вопрос | OCR, школьные знания, логика | Exact match, answer judge, evidence | P1 |
| UniScienceVQA | Университетская страница + вопрос | OCR, профильные знания, логика | Exact match, answer judge, evidence | P1 |

`evidence` обязателен: модель указывает страницу и область документа; для
таблицы — строку и ячейку. Для P0-наборов добавляется контролируемая ошибка
документа, поэтому считаются ложное принятие и ложное отклонение, а не только
точность QA.

## Вспомогательная визуальная дорожка

Эти задачи остаются в постоянном каталоге как тесты восприятия. Они войдут в
итоговый DocBench score только после привязки примеров к русским документам.

| Задача | Проверяемые навыки | Роль |
| --- | --- | --- |
| RealVQA | Реальный визуальный контекст, логика, знания о мире | Визуальный baseline |
| ruCLEVR | Количество, объекты, пространственное рассуждение | Контролируемая диагностика |
| ruCommonVQA | Объекты, действия, расположение, логика | Визуальный baseline |
| ruHHH-Image | OCR, безопасность, этика, рассуждение | Safety-дорожка |
| WEIRD | Соответствие реальному миру, объекты и события | Проверка здравого смысла |

## Профессиональные знания

Эти русские multiple-choice задачи полезны как отдельный score знаний. Они не
заменяют документную проверку: для основного результата DocBench всё равно
нужны документ и evidence.

| Задача | Домен | Вход | Оценка |
| --- | --- | --- | --- |
| ruTXTAgroBench | Сельское хозяйство | Вопрос + варианты | F1 exact match |
| ruTXTAquaBench | Аквакультура | Вопрос + варианты | F1 exact match |
| ruTXTMedQFundamental | Фундаментальная медицина | Вопрос + варианты | F1 exact match |

## Русское рассуждение и длинный контекст

Эта дорожка проверяет, что документная модель не теряет способность рассуждать
после OCR и извлечения текста. Её score публикуется отдельно от conformance.

| Задача | Проверяемые навыки | Ответ и оценка |
| --- | --- | --- |
| Luzitania | Многошаговое математическое рассуждение | Проверяемый итоговый ответ; exact match |
| ruAIME | Олимпиадная математика и глубокое рассуждение | Проверяемый итоговый ответ; exact match |
| T-Math | Русские олимпиадные задачи | Только итоговый ответ; exact match |
| MMReD | Длинный контекст, плотная агрегация, счёт и временная логика | Короткий ответ; exact match |

## Неподвижный контракт примера

Каждый основной пример имеет `document_page_image`, `question`, `gold_answer`,
`gold_evidence`, `language: ru` и воспроизводимый идентификатор. Внешние
названия выше — таксономические метки; они не являются импортом чужого
датасета.
